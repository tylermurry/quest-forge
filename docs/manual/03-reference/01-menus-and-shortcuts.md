# Menus and keyboard shortcuts

Every command in the editor's menus, with its shortcut on a Mac and on Windows and Linux.

Shortcuts that are a single key, such as **P** for the Polygon Tool, don't work while you're typing in a field.

## File

| Command | Mac | Windows / Linux | What it does |
|---|---|---|---|
| **New Project…** | ⌘N | Ctrl+N | Starts a new project. |
| **Open Folder…** | ⌘O | Ctrl+O | Opens a project folder. |
| **Save** | ⌘S | Ctrl+S | Saves your changes to the project folder. |
| **Build Game…** | ⌘B | Ctrl+B | Builds the game into a `.quest` file. |
| **Back to Project Selector** | ⌘⇧W | Ctrl+Shift+W | Closes the project and returns to the start screen. |

## Edit

| Command | Mac | Windows / Linux | What it does |
|---|---|---|---|
| **Undo** | ⌘Z | Ctrl+Z | Undoes the last change. In a text field, undoes typing. |
| **Redo** | ⌘⇧Z | Ctrl+Shift+Z or Ctrl+Y | Redoes what you undid. |
| **Delete** | ⌫ | Backspace or Delete | Deletes what's selected. |

## View

| Command | Mac | Windows / Linux | What it does |
|---|---|---|---|
| **Project Browser** | ⌘1 | Ctrl+1 | Shows or hides the Project Browser. |
| **Inspector** | ⌘2 | Ctrl+2 | Shows or hides the Inspector. |
| **Problems** | ⌘3 | Ctrl+3 | Shows or hides the Problems panel. |
| **Hide All Panels** | ⌘\\ | Ctrl+\\ | Hides every panel but the editor tabs, or brings them back. Hiding them while a scene is open zooms the scene to fit. |

## Scene

Work when a scene is open.

| Command | Mac | Windows / Linux | What it does |
|---|---|---|---|
| **Select / Move Tool** | V | V | Select, move and reshape things. |
| **Polygon Tool** | P | P | Draw a shape point by point. |
| **Rectangle Tool** | R | R | Draw a rectangle. |
| **Spawn Point Tool** | S | S | Place a spawn point. |
| **Walk-to Point Tool** | W | W | Set where the player stands to use a hotspot. |
| **Finish Shape** | Return | Enter | Closes the shape you're drawing. |
| **Cancel Shape** | Esc | Esc | Throws away the shape you're drawing. |
| **Bring Forward** | ] | ] | Moves the selected object one place toward the front. |
| **Send Backward** | [ | [ | Moves the selected object one place toward the back. |
| **Bring to Front** | ⌘] | Ctrl+] | Moves the selected object in front of everything. |
| **Send to Back** | ⌘[ | Ctrl+[ | Moves the selected object behind everything. |
| **Snap to Vertices and Edges** | — | — | Turns snapping on or off. |
| **Zoom In** | ⌘= | Ctrl+= | Zooms in. |
| **Zoom Out** | ⌘- | Ctrl+- | Zooms out. |
| **Zoom to Fit** | ⌘0 | Ctrl+0 | Fits the whole scene in view. |
| **Actual Size (1×)** | — | — | Shows the scene at its real size. |

## Dialogue

Work when a dialogue is open.

| Command | What it does |
|---|---|
| **Auto-Layout** | Arranges the nodes neatly. |
| **Fit Graph in View** | Brings the whole graph into view. |

## Play

| Command | Mac | Windows / Linux | What it does |
|---|---|---|---|
| **Play** | F5 | F5 | Playtests from the start of the game. |
| **Play from Here** | F6 | F6 | Playtests from the scene you're editing. |
| **Play from This Node** | Shift+F6 | Shift+F6 | Playtests the selected dialogue node. |
| **Restart** | — | — | Goes back to where this playtest started. |
| **Restart Scene** | — | — | Goes back to when the player entered this scene. |
| **Stop** | Shift+F5 | Shift+F5 | Ends the playtest. |

## Other shortcuts

| Where | Keys | What they do |
|---|---|---|
| Scene canvas | Hold Space and drag | Pans the view. |
| Scene canvas | Two-finger scroll | Pans the view. |
| Scene canvas | Pinch, or scroll with ⌘ / Ctrl held | Zooms where the pointer is. |
| Drawing a shape | ⌫ / Backspace | Removes the last point. |
| Select / Move Tool | Alt-click a point | Deletes the point. |
| Playtest | Esc | Takes keyboard focus away from the game. |
