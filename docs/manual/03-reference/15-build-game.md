# Build Game and .quest files

## Build Game…

**File ▸ Build Game…** (⌘B / Ctrl+B) builds your game into one `.quest` file.

1. Quest Forge checks the game. If there are errors, it opens **Problems** instead and asks you to fix them.
2. You choose where to save the file. It's named after your game.
3. A notice says **Game built** when it's done.

Build Game uses what's in the editor, including changes you haven't saved.

## What's in a .quest file

Everything needed to play: game settings, every scene, item, character, dialogue, flag and rule, and every
picture, sound and font the game uses. Images, sounds and fonts nothing uses are left out.

## Playing a .quest file

On the Quest Forge website, open **Play** and click **Choose a .quest file**, or drop the file on the page.
**Choose another file** switches to a different game.

The game runs in any modern web browser, on a computer, tablet or phone. Nothing is installed, and the file
isn't uploaded anywhere: it plays in the browser.

Saved games and volume settings are kept in that browser, for that game.

## Newer files

A `.quest` file built by a newer version of Quest Forge than the player is using says so instead of playing.
