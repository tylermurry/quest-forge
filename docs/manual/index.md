# Quest Forge manual

Quest Forge lets you make a classic point-and-click adventure without writing code. You paint the rooms,
show where people can walk, and write what happens in plain sentences. Quest Forge turns it into a game anyone
can play in a web browser, on a computer or a phone.

This manual is for anyone with a story to tell. You don't need to know how to program.

## How this manual is organized

- **[Concepts](./01-concepts/01-how-quest-forge-works.md)** explain how Quest Forge thinks about a game. Read these
  first: every other page builds on them.
- **[Guides](./02-guides/01-start-a-project.md)** walk you through making each part of a game, from your first scene
  to sharing the finished file.
- **[Reference](./03-reference/01-menus-and-shortcuts.md)** describes every panel, menu, field, rule and setting.
  Use it to look something up.
